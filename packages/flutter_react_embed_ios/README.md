# flutter_react_embed_ios

The iOS implementation of [`flutter_react_embed`](https://pub.dev/packages/flutter_react_embed). It hosts React web apps in a `WKWebView` served from Flutter assets, as a platform view.

## Usage

This package is [endorsed](https://docs.flutter.dev/packages-and-plugins/developing-packages#endorsed-federated-plugin): depend on `flutter_react_embed` and it is included automatically.

```sh
flutter pub add flutter_react_embed
```

Add `flutter_react_embed_ios` to your `pubspec.yaml` directly only if you import its APIs, which it does not currently expose.

See the [`flutter_react_embed` documentation](https://pub.dev/packages/flutter_react_embed) for usage.
